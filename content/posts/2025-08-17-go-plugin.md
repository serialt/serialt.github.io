## 2、hashicorp/go-plugin

`hashicorp/go-plugin` 是一个基于 RPC 的 Go 插件系统，已被 HashiCorp 的 Terraform、Nomad、Vault、Boundary、Waypoint 等生产级工具使用了超过四年，在数百万台机器上经过验证。

其核心架构是：**插件作为独立子进程运行，通过本地回环网络与宿主进程进行 RPC 通信**（`net/rpc` 或 gRPC）。这种设计带来几个关键优势：

- **故障隔离**：插件 panic 不会导致宿主进程崩溃
- **跨语言支持**：基于 gRPC 的插件可以用任何主流语言编写
- **自然的使用体验**：对插件作者而言，只需实现一个 Go 接口；对宿主而言，调用插件方法如同调用本地函数

> **重要限制**：go-plugin 仅设计用于**本地可靠网络**（回环地址或 Unix socket）。跨真实网络的插件部署不受支持，会导致不可预期的行为。

### 2.1 核心概念

#### 2.1.1 握手协议

宿主启动插件子进程后，插件向 **stdout** 输出一行握手信息，格式为：

```
CORE-PROTOCOL-VERSION | APP-PROTOCOL-VERSION | NETWORK-TYPE | NETWORK-ADDR | PROTOCOL
```

例如：`1|1|tcp|127.0.0.1:12345|grpc`

- `CORE-PROTOCOL-VERSION`：go-plugin 自身的协议版本，当前固定为 `1`
- `APP-PROTOCOL-VERSION`：应用自定义的协议版本，用于接口变更时的兼容性管理
- `NETWORK-TYPE`：`tcp` 或 `unix`
- `NETWORK-ADDR`：监听地址
- `PROTOCOL`：`grpc` 或 `netrpc`

**关键约束**：插件**绝不能**向 stdout 写入其他任何内容。所有日志必须输出到 stderr，否则握手会失败。

#### 2.1.2 握手配置（HandshakeConfig）

握手配置用于防止宿主误连到错误的二进制文件，是用户体验层面的保护（非安全机制）：

```go
var Handshake = plugin.HandshakeConfig{
    ProtocolVersion:  1,
    MagicCookieKey:   "MY_PLUGIN",
    MagicCookieValue: "unique-cookie-value",
}
```

`MagicCookieKey` 和 `MagicCookieValue` 一旦设定，**永远不要修改**，否则所有已部署的插件将无法被加载。

#### 2.1.3 插件映射（PluginMap）

宿主和插件通过一个 `map[string]plugin.Plugin` 来标识和分发插件。键名是插件标识符（如 `"greeter"`），值是实现了 `plugin.Plugin` 接口的结构体。宿主通过 `Dispense("greeter")` 获取对应的插件实例。

| 特性     | net/rpc              | gRPC                 |
| :------- | :------------------- | :------------------- |
| 语言支持 | 仅 Go                | 任意语言             |
| 定义方式 | Go 接口 + RPC 包装   | Protobuf 服务定义    |
| 流式传输 | 不支持               | 支持                 |
| 推荐场景 | 纯 Go 生态、简单接口 | 跨语言、生产级新项目 |



### 2.2 net/rpc 使用

`shared/interface.go`

```go
package shared

import (
	"net/rpc"

	"github.com/hashicorp/go-plugin"
)

// Handshake 是宿主和插件之间的握手配置。
// MagicCookieKey/Value 一旦发布，不应修改。
var Handshake = plugin.HandshakeConfig{
	ProtocolVersion:  1,
	MagicCookieKey:   "GREETER_PLUGIN",
	MagicCookieValue: "greeter-secret-cookie",
}

// Greeter 是插件暴露的业务接口。
type Greeter interface {
	Greet(name string) (string, error)
}

// GreeterRPC 是宿主侧的 RPC 客户端，实现 Greeter 接口。
type GreeterRPC struct {
	client *rpc.Client
}

func (g *GreeterRPC) Greet(name string) (string, error) {
	var resp string
	// 调用插件端注册的 "Plugin.Greet" 方法
	err := g.client.Call("Plugin.Greet", name, &resp)
	return resp, err
}

// GreeterRPCServer 是插件侧的 RPC 服务端，接收调用并委托给真实实现。
type GreeterRPCServer struct {
	Impl Greeter // 真实的业务实现
}

func (s *GreeterRPCServer) Greet(name string, resp *string) error {
	result, err := s.Impl.Greet(name)
	if err != nil {
		return err
	}
	*resp = result
	return nil
}

// GreeterPlugin 实现 plugin.Plugin 接口。
// Server 返回 RPC 服务端，Client 返回 RPC 客户端。
type GreeterPlugin struct {
	Impl Greeter // 插件端注入真实实现；宿主端留空
}

func (p *GreeterPlugin) Server(*plugin.MuxBroker) (interface{}, error) {
	return &GreeterRPCServer{Impl: p.Impl}, nil
}

func (p *GreeterPlugin) Client(_ *plugin.MuxBroker, c *rpc.Client) (interface{}, error) {
	return &GreeterRPC{client: c}, nil
}

```

`plugin/main.go`

```go
package main

import (
	"fmt"

	"pluginc/shared"

	"github.com/hashicorp/go-plugin"
)

// greeterImpl 是 Greeter 接口的真实实现。
type greeterImpl struct{}

func (g *greeterImpl) Greet(name string) (string, error) {
	return fmt.Sprintf("Hello, %s! (from net/rpc plugin)", name), nil
}

func main() {
	plugin.Serve(&plugin.ServeConfig{
		HandshakeConfig: shared.Handshake,
		Plugins: map[string]plugin.Plugin{
			"greeter": &shared.GreeterPlugin{
				Impl: &greeterImpl{},
			},
		},
		// 不设置 GRPCServer，即走 net/rpc
	})
}

```

`cmd/main.go`

```go
package main

import (
	"fmt"
	"log"
	"os/exec"

	"pluginc/shared"

	"github.com/hashicorp/go-plugin"
)

func main() {
	// 创建客户端，指定插件二进制路径
	client := plugin.NewClient(&plugin.ClientConfig{
		HandshakeConfig: shared.Handshake,
		Plugins: map[string]plugin.Plugin{
			"greeter": &shared.GreeterPlugin{},
		},
		Cmd:              exec.Command("./plugin/greeter"),
		AllowedProtocols: []plugin.Protocol{plugin.ProtocolNetRPC}, // 限定仅 net/rpc
	})
	defer client.Kill() // 宿主退出时终止插件进程

	// 建立 RPC 连接
	rpcClient, err := client.Client()
	if err != nil {
		log.Fatal("failed to create client: ", err)
	}

	// 获取名为 "greeter" 的插件实例
	raw, err := rpcClient.Dispense("greeter")
	if err != nil {
		log.Fatal("failed to dispense plugin: ", err)
	}

	// 类型断言回 Greeter 接口，像本地方法一样调用
	greeter := raw.(shared.Greeter)
	msg, err := greeter.Greet("World")
	if err != nil {
		log.Fatal("call failed: ", err)
	}
	fmt.Println(msg)
}

```

### 2.3 gRPC 使用

`buf`

```yaml
# buf.yaml
version: v2
modules:
  - path: api
deps:
  - buf.build/googleapis/googleapis
  
# buf.gen.yaml
version: v2
inputs:
  - directory: api
plugins:
  - local: ["go", "run", "google.golang.org/protobuf/cmd/protoc-gen-go@v1.36.11"]
    out: api
    opt: paths=source_relative
  - local: ["go", "run", "google.golang.org/grpc/cmd/protoc-gen-go-grpc@v1.6.2"]
    out: api
    opt: paths=source_relative
```

`api`

```protobuf
// api/hello/hello.proto

syntax = "proto3";
package hello;
option go_package = "plugin-grpc/hello;v1";

service Greeter {
    rpc Greet(GreetRequest) returns (GreetResponse);
}

message GreetRequest {
    string name = 1;
}

message GreetResponse {
    string message = 1;
}
```

```go
// cmd/main.go
package main

import (
	"fmt"
	"log"
	"os/exec"

	"plugin-grpc/shared"

	"github.com/hashicorp/go-plugin"
)

func main() {
	client := plugin.NewClient(&plugin.ClientConfig{
		HandshakeConfig: shared.Handshake,
		Plugins: map[string]plugin.Plugin{
			"greeter": &shared.GreeterGRPCPlugin{},
		},
		Cmd:              exec.Command("./plugin/greeter"),
		AllowedProtocols: []plugin.Protocol{plugin.ProtocolGRPC},
	})
	defer client.Kill()

	rpcClient, err := client.Client()
	if err != nil {
		log.Fatal(err)
	}

	raw, err := rpcClient.Dispense("greeter")
	if err != nil {
		log.Fatal(err)
	}

	greeter := raw.(shared.Greeter)
	msg, err := greeter.Greet("Buf")
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(msg)
}
```
